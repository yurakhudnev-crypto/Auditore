# 📱 Настройка приложения для всех устройств

## ⚠️ ВАЖНО: Как работают настройки

Настройки приложения (каталог и форма для результатов) хранятся в файле `config.json` на GitHub. Это означает:

✅ **Плюсы:**
- Все ученики видят одинаковые настройки на любом устройстве
- Не нужно настраивать приложение на каждом устройстве
- Настройки сохраняются навсегда

❌ **Минусы:**
- После изменения настроек нужно загружать файл на GitHub
- Обновление занимает 1-2 минуты

---

## 🔧 Как настроить каталог

### Шаг 1: Откройте настройки
1. Откройте приложение на компьютере
2. Перейдите в **Teacher → Catalog → CATALOG SETTINGS**

### Шаг 2: Введите URL каталога
1. Вставьте ссылку на папку с песнями (Google Drive, Dropbox и т.д.)
2. Нажмите **SAVE**
3. Скачается файл `config.json`

### Шаг 3: Загрузите файл на GitHub
1. Откройте ваш репозиторий на GitHub
2. Нажмите на файл `config.json`
3. Нажмите на карандаш (Edit)
4. Удалите старое содержимое
5. Откройте скачанный `config.json` в текстовом редакторе
6. Скопируйте всё содержимое
7. Вставьте в GitHub
8. Нажмите **Commit changes**
9. Подождите 1-2 минуты

### Шаг 4: Проверьте
1. Откройте приложение на телефоне (ссылка `#student`)
2. Нажмите **OPEN CATALOG**
3. Должна открыться ваша папка в облаке

---

## 🔧 Как настроить форму для результатов

### Шаг 1: Создайте Google Form
1. Откройте [forms.google.com](https://forms.google.com)
2. Создайте новую форму с 8 полями:
   - First Name (короткий ответ)
   - Last Name (короткий ответ)
   - Class (короткий ответ)
   - Song Title (короткий ответ)
   - Score (короткий ответ)
   - Total Gaps (короткий ответ)
   - Percentage (короткий ответ)
   - Translations (абзац)

### Шаг 2: Получите URL и Entry IDs
1. Нажмите **Отправить** → иконка ссылки 🔗
2. Скопируйте URL формы
3. Нажмите **⋮** → **Получить предзаполненную форму**
4. Заполните все поля тестовыми данными
5. Нажмите **Получить ссылку**
6. Скопируйте ссылку и извлеките Entry ID:
   ```
   https://docs.google.com/forms/.../viewform?entry.123456789=test1&entry.234567890=test2...
   ```
   - `entry.123456789` → First Name
   - `entry.234567890` → Last Name
   - и т.д.

### Шаг 3: Настройте приложение
1. Откройте приложение на компьютере
2. Перейдите в **Teacher → Results (03)**
3. Вставьте:
   - **Form URL**: URL формы
   - **Entry IDs**: ID для каждого поля
4. Нажмите **SAVE**
5. Скачается файл `config.json`

### Шаг 4: Загрузите файл на GitHub
1. Откройте ваш репозиторий на GitHub
2. Нажмите на файл `config.json`
3. Нажмите на карандаш (Edit)
4. Удалите старое содержимое
5. Откройте скачанный `config.json` в текстовом редакторе
6. Скопируйте всё содержимое
7. Вставьте в GitHub
8. Нажмите **Commit changes**
9. Подождите 1-2 минуты

### Шаг 5: Проверьте
1. Откройте приложение на телефоне (ссылка `#student`)
2. Выполните упражнение
3. Нажмите **SEND TO TEACHER**
4. Должна открыться Google Form с предзаполненными данными

## 📝 Формат файла config.json

Файл `config.json` должен выглядеть так:

```json
{
  "catalogUrl": "https://drive.google.com/drive/folders/YOUR_FOLDER_ID",
  "googleForm": {
    "url": "https://docs.google.com/forms/d/e/YOUR_FORM_ID/viewform",
    "entryIds": {
      "firstName": "123456789",
      "lastName": "234567890",
      "className": "345678901",
      "songTitle": "456789012",
      "score": "567890123",
      "totalGaps": "678901234",
      "percentage": "789012345",
      "translations": "890123456"
    }
  }
}
```

## 🔄 Как обновить настройки

Если вам нужно изменить настройки:

1. Измените настройки в приложении (Teacher → Catalog или Results)
2. Нажмите **SAVE**
3. Скачается новый файл `config.json`
4. Загрузите его на GitHub (замените старый)
5. Подождите 1-2 минуты
6. Готово! Все ученики увидят новые настройки

## 🐛 Решение проблем

### Проблема: Настройки не применяются
**Решение:**
1. Убедитесь, что загрузили `config.json` на GitHub
2. Подождите 1-2 минуты для обновления
3. Очистите кэш браузера на телефоне
4. Попробуйте открыть приложение заново

### Проблема: Каталог не открывается
**Решение:**
1. Проверьте, что URL каталога правильный в `config.json`
2. Убедитесь, что папка доступна по ссылке
3. Проверьте права доступа к папке

### Проблема: Форма не отправляется
**Решение:**
1. Проверьте, что URL формы правильный в `config.json`
2. Проверьте, что Entry ID заполнены правильно
3. Убедитесь, что форма доступна для отправки

## 💡 Советы

1. **Сохраните копию config.json** на компьютере как резервную копию
2. **Тестируйте на телефоне** после каждого изменения настроек
3. **Используйте один браузер** для настройки (чтобы не путаться)
4. **Записывайте изменения** в настройках, чтобы помнить, что меняли
