# 📊 Настройка Google Forms для сбора результатов

## 🎯 Что это и зачем

Google Forms позволяет автоматически собирать результаты учеников в Google Таблицу. Ученик нажимает "SEND TO TEACHER", и данные автоматически отправляются в форму.

## 📋 Пошаговая инструкция

### Шаг 1: Создайте Google Form

1. Откройте [Google Forms](https://forms.google.com)
2. Нажмите **"Пустая форма"** (или "+")
3. Назовите форму: **"Audiotore Results"**

### Шаг 2: Добавьте поля формы

Добавьте следующие поля **в этом порядке**:

1. **First Name** (Имя)
   - Тип: **Короткий ответ** (Short answer)
   - Обязательное: ✅

2. **Last Name** (Фамилия)
   - Тип: **Короткий ответ** (Short answer)
   - Обязательное: ✅

3. **Class** (Класс)
   - Тип: **Короткий ответ** (Short answer)
   - Обязательное: ✅

4. **Song Title** (Название песни)
   - Тип: **Короткий ответ** (Short answer)
   - Обязательное: ✅

5. **Score** (Результат)
   - Тип: **Короткий ответ** (Short answer)
   - Обязательное: ✅
   - Пример: "8/10"

6. **Total Gaps** (Всего пропусков)
   - Тип: **Короткий ответ** (Short answer)
   - Обязательное: ✅

7. **Percentage** (Процент)
   - Тип: **Короткий ответ** (Short answer)
   - Обязательное: ✅
   - Пример: "80%"

8. **Translations** (Переводы)
   - Тип: **Абзац** (Paragraph)
   - Обязательное: ❌ (необязательное)

### Шаг 3: Настройте форму

1. Нажмите на **Настройки** (шестерёнка вверху)
2. Включите **"Собирать адреса электронной почты"** - ❌ **ВЫКЛЮЧИТЕ** (не нужно)
3. Включите **"Ограничить до 1 ответа"** - ❌ **ВЫКЛЮЧИТЕ** (ученики будут отправлять несколько раз)
4. Включите **"Редактирование после отправки"** - ❌ **ВЫКЛЮЧИТЕ**

### Шаг 4: Получите URL формы

1. Нажмите **"Отправить"** (вверху справа)
2. Нажмите на иконку **ссылки** (🔗)
3. Включите **"Сократить URL"** - ❌ **ВЫКЛЮЧИТЕ** (нужен полный URL)
4. Скопируйте URL
5. URL должен заканчиваться на `/viewform`

Пример:
```
https://docs.google.com/forms/d/e/1FAIpQLSe.../viewform
```

### Шаг 5: Найдите Entry ID для каждого поля

Это самый важный шаг! Нужно найти ID каждого поля формы.

#### Метод 1: Через предзаполненную ссылку (проще)

1. В форме нажмите на **три точки** (⋮) вверху справа
2. Выберите **"Получить предзаполненную форму"** (Get pre-filled form)
3. Заполните все поля тестовыми данными:
   - First Name: `test1`
   - Last Name: `test2`
   - Class: `test3`
   - Song Title: `test4`
   - Score: `test5`
   - Total Gaps: `test6`
   - Percentage: `test7`
   - Translations: `test8`
4. Нажмите **"Получить ссылку"** (Get link)
5. Скопируйте ссылку

Ссылка будет выглядеть так:
```
https://docs.google.com/forms/d/e/1FAIpQLSe.../viewform?entry.123456789=test1&entry.234567890=test2&entry.345678901=test3&entry.456789012=test4&entry.567890123=test5&entry.678901234=test6&entry.789012345=test7&entry.890123456=test8
```

6. Извлеките Entry ID из URL:
   - `entry.123456789` → First Name
   - `entry.234567890` → Last Name
   - `entry.345678901` → Class
   - `entry.456789012` → Song Title
   - `entry.567890123` → Score
   - `entry.678901234` → Total Gaps
   - `entry.789012345` → Percentage
   - `entry.890123456` → Translations

#### Метод 2: Через код страницы (сложнее)

1. Откройте форму в браузере
2. Нажмите правой кнопкой на поле "First Name"
3. Выберите **"Просмотреть код"** (Inspect)
4. Найдите атрибут `name="entry.XXXXX"`
5. Запишите число после `entry.`
6. Повторите для всех полей

### Шаг 6: Настройте приложение

1. Откройте приложение как учитель
2. Перейдите в **Student** режим (или откройте ссылку `?student`)
3. Выполните упражнение до конца
4. На финальном экране нажмите **"SETUP GOOGLE FORM"**
5. Вставьте:
   - **Form URL**: URL из Шага 4
   - **Entry IDs**: ID из Шага 5 для каждого поля
6. Нажмите **"SAVE"**

### Шаг 7: Проверьте работу

1. Откройте приложение как ученик (ссылка `#student`)
2. Выполните упражнение
3. Нажмите **"SEND TO TEACHER"**
4. Должна открыться новая вкладка с Google Form
5. Все поля должны быть предзаполнены данными
6. Нажмите **"Отправить"** в форме
7. Проверьте Google Таблицу (связанную с формой) - данные должны появиться

## 📊 Просмотр результатов

Все результаты автоматически сохраняются в Google Таблицу:

1. Откройте вашу Google Form
2. Нажмите на вкладку **"Ответы"** (Responses)
3. Нажмите на иконку **Google Sheets** (зелёный значок)
4. Создайте новую таблицу или выберите существующую
5. Все результаты будут автоматически добавляться в таблицу

## 🔧 Решение проблем

### Проблема: Форма не открывается
**Решение:** Проверьте, что URL формы правильный и заканчивается на `/viewform`

### Проблема: Поля не заполняются
**Решение:** Проверьте Entry ID - они должны быть в формате `entry.123456789` (только числа после точки)

### Проблема: Данные не сохраняются в таблицу
**Решение:** Убедитесь, что форма связана с Google Таблицей (вкладка "Ответы" → иконка Sheets)

### Проблема: Ученик видит форму Google
**Решение:** Это нормально! Форма открывается в новой вкладке, ученик просто нажимает "Отправить"

## 💡 Советы

1. **Сделайте копию формы** для каждого класса, чтобы легче анализировать результаты
2. **Настройте уведомления** на почту, чтобы получать уведомления о новых ответах
3. **Используйте фильтры** в Google Таблице для анализа результатов по классам
4. **Экспортируйте таблицу** в Excel для дополнительного анализа
