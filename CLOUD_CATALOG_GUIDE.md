# 📚 Руководство по использованию каталога через облачное хранилище

## 🎯 Новая простая система

Теперь каталог работает через облачное хранилище (Google Drive, Dropbox, OneDrive и т.д.) без сложной настройки API!

## 📋 Как это работает

### Для учителя:

1. **Загрузите JSON файлы** с песнями в папку на облачном хранилище
2. **Скопируйте ссылку** на эту папку
3. **Настройте каталог** в приложении:
   - Откройте "Teacher Workspace"
   - Выберите "Catalog"
   - Нажмите "CATALOG SETTINGS"
   - Вставьте ссылку на папку
   - Нажмите "SAVE"

### Для ученика:

1. **Откройте приложение** по ссылке `?student`
2. **Введите данные** (имя, фамилия, класс)
3. **Нажмите "OPEN CATALOG"**
4. **Откроется папка** в облачном хранилище
5. **Скачайте JSON файл** с нужной песней
6. **Загрузите файл** в приложение через кнопку "UPLOAD JSON FILE"
7. **Выполните упражнение**

## 🔧 Настройка для учителя

### Шаг 1: Создайте папку в облаке

**Google Drive:**
1. Откройте [drive.google.com](https://drive.google.com)
2. Создайте новую папку (например, "Audiotore Songs")
3. Загрузите JSON файлы с песнями в эту папку
4. Нажмите правой кнопкой на папку → "Поделиться"
5. Измените доступ на "Все, у кого есть ссылка"
6. Скопируйте ссылку

**Dropbox:**
1. Создайте папку
2. Загрузите файлы
3. Нажмите "Share" → "Create link"
4. Скопируйте ссылку

**OneDrive:**
1. Создайте папку
2. Загрузите файлы
3. Нажмите "Share" → "Copy link"
4. Скопируйте ссылку

### Шаг 2: Настройте каталог в приложении

1. Откройте приложение
2. Перейдите в "Teacher" → "Catalog"
3. Нажмите "CATALOG SETTINGS"
4. Вставьте ссылку на папку
5. Нажмите "TEST LINK" для проверки
6. Нажмите "SAVE"

### Шаг 3: Проверьте работу

1. Откройте ссылку для учеников (`?student`)
2. Введите тестовые данные
3. Нажмите "OPEN CATALOG"
4. Должна открыться ваша папка в облаке
5. Скачайте любой JSON файл
6. Загрузите его в приложение

## 📁 Структура файлов

Все JSON файлы должны быть в **корне папки** (не в подпапках):

```
Audiotore Songs/ (ваша папка)
├── let-it-be.json
├── imagine.json
├── hey-jude.json
└── yesterday.json
```

## 🎵 Формат JSON файла

Каждый JSON файл должен иметь следующую структуру:

```json
{
  "title": "Let It Be",
  "lines": [
    {
      "words": [
        {
          "word": "When",
          "translation": "Когда",
          "isGap": false
        },
        {
          "word": "find",
          "translation": "нахожу",
          "isGap": true,
          "correctAnswer": "find",
          "wrongAnswers": ["lose", "seek"]
        }
      ],
      "studentTranslation": ""
    }
  ]
}
```

## 🐛 Решение проблем

### Проблема: "CATALOG NOT CONFIGURED"
**Решение:** Учитель должен настроить ссылку на каталог в "Catalog Settings"

### Проблема: Ссылка не открывается
**Решение:** 
1. Проверьте, что ссылка правильная
2. Убедитесь, что папка доступна по ссылке
3. Проверьте права доступа к папке

### Проблема: Файл не загружается
**Решение:**
1. Убедитесь, что файл имеет расширение `.json`
2. Проверьте, что файл не поврежден
3. Попробуйте скачать файл вручную и открыть в текстовом редакторе

## 💡 Советы

### Для учителя:
- Организуйте песни по папкам (например, "Easy", "Medium", "Hard")
- Используйте понятные имена файлов (например, "beatles-let-it-be.json")
- Регулярно делайте резервные копии файлов

### Для учеников:
- Всегда скачивайте файлы из каталога, а не используйте старые версии
- Если файл не загружается, попробуйте скачать его снова
- Сохраняйте результаты после выполнения упражнения
