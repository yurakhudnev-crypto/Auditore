# 📊 Настройка Google Form для учителя

## ⚡ Быстрая настройка (5 минут)

### 1. Создайте Google Form

1. Откройте [forms.google.com](https://forms.google.com)
2. Создайте новую форму
3. Добавьте 8 полей:

| Поле | Тип | Обязательно |
|------|-----|-------------|
| First Name | Короткий ответ | ✅ |
| Last Name | Короткий ответ | ✅ |
| Class | Короткий ответ | ✅ |
| Song Title | Короткий ответ | ✅ |
| Score | Короткий ответ | ✅ |
| Total Gaps | Короткий ответ | ✅ |
| Percentage | Короткий ответ | ✅ |
| Translations | Абзац | ❌ |

### 2. Получите URL формы

1. Нажмите **"Отправить"** (вверху справа)
2. Нажмите на иконку **ссылки** 🔗
3. Скопируйте URL (должен заканчиваться на `/viewform`)

Пример:
```
https://docs.google.com/forms/d/e/1FAIpQLSe.../viewform
```

### 3. Получите Entry ID для каждого поля

**Самый простой способ:**

1. В форме нажмите **⋮** (три точки) → **"Получить предзаполненную форму"**
2. Заполните все поля тестовыми данными:
   - First Name: `test1`
   - Last Name: `test2`
   - Class: `test3`
   - Song Title: `test4`
   - Score: `test5`
   - Total Gaps: `test6`
   - Percentage: `test7`
   - Translations: `test8`
3. Нажмите **"Получить ссылку"**
4. Скопируйте ссылку

Ссылка будет выглядеть так:
```
https://docs.google.com/forms/d/e/.../viewform?entry.123456789=test1&entry.234567890=test2&entry.345678901=test3&entry.456789012=test4&entry.567890123=test5&entry.678901234=test6&entry.789012345=test7&entry.890123456=test8
```

5. Извлеките Entry ID из URL:
   - `entry.123456789` → First Name
   - `entry.234567890` → Last Name
   - `entry.345678901` → Class
   - `entry.456789012` → Song Title
   - `entry.567890123` → Score
   - `entry.678901234` → Total Gaps
   - `entry.789012345` → Percentage
   - `entry.890123456` → Translations

### 4. Настройте приложение

1. Откройте приложение
2. Перейдите в **Teacher** → **Results** (03)
3. Вставьте:
   - **Form URL**: URL из шага 2
   - **Entry IDs**: ID из шага 3 для каждого поля
4. Нажмите **"SAVE"**

### 5. Готово! ✅

Теперь ученики могут нажимать **"SEND TO TEACHER"** после выполнения упражнения, и результаты автоматически отправляются в Google Form → Google Таблицу.

---

## 📋 Как это работает

```
Ученик выполняет упражнение
         ↓
Нажимает "SEND TO TEACHER"
         ↓
Открывается Google Form с предзаполненными данными
         ↓
Ученик нажимает "Отправить" в форме
         ↓
Результаты автоматически сохраняются в Google Таблицу
```

---

## 📊 Просмотр результатов

1. Откройте Google Form
2. Вкладка **"Ответы"** → иконка Google Sheets
3. Все результаты автоматически появляются в таблице

---

## 🔧 Решение проблем

### Проблема: Ученик видит ошибку "FORM NOT CONFIGURED"
**Решение:** Учитель должен настроить Google Form в Teacher → Results (03)

### Проблема: Форма открывается, но поля не заполняются
**Решение:** Проверьте Entry ID - они должны быть в формате `entry.123456789`

### Проблема: Данные не сохраняются в таблицу
**Решение:** Убедитесь, что форма связана с Google Таблицей (вкладка "Ответы" → иконка Sheets)
