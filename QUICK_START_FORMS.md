# 🚀 Быстрый старт: Настройка сбора результатов

## 📋 Что нужно сделать (5 минут)

### 1. Создайте Google Form

1. Откройте [forms.google.com](https://forms.google.com)
2. Создайте новую форму "Audiotore Results"
3. Добавьте 8 полей:
   - **First Name** (короткий ответ)
   - **Last Name** (короткий ответ)
   - **Class** (короткий ответ)
   - **Song Title** (короткий ответ)
   - **Score** (короткий ответ)
   - **Total Gaps** (короткий ответ)
   - **Percentage** (короткий ответ)
   - **Translations** (абзац)

### 2. Получите URL формы

1. Нажмите "Отправить" → иконка ссылки 🔗
2. Скопируйте URL (должен заканчиваться на `/viewform`)

### 3. Найдите Entry ID

1. В форме нажмите ⋮ → "Получить предзаполненную форму"
2. Заполните все поля тестовыми данными (test1, test2, test3...)
3. Нажмите "Получить ссылку"
4. Скопируйте ссылку
5. Извлеките Entry ID из URL:
   ```
   https://docs.google.com/forms/.../viewform?entry.123456789=test1&entry.234567890=test2...
   ```
   - `entry.123456789` → First Name
   - `entry.234567890` → Last Name
   - и т.д.

### 4. Настройте приложение

1. Откройте приложение → Teacher → **Results** (03)
2. Вставьте:
   - **Form URL**: URL из шага 2
   - **Entry IDs**: ID из шага 3 для каждого поля
3. Нажмите **SAVE**

### 5. Готово! ✅

Теперь ученики могут нажимать **"SEND TO TEACHER"** после выполнения упражнения, и результаты автоматически отправляются в Google Forms → Google Таблицу.

## 💡 Как это работает

```
Ученик выполняет упражнение
         ↓
Нажимает "SEND TO TEACHER"
         ↓
Открывается Google Form с предзаполненными данными
         ↓
Ученик нажимает "Отправить" в форме
         ↓
Результаты автоматически сохраняются в Google Таблицу
```

## 📊 Просмотр результатов

1. Откройте Google Form
2. Вкладка "Ответы" → иконка Google Sheets
3. Все результаты автоматически появляются в таблице
