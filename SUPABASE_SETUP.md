# 🚀 Настройка Supabase для Audiotore

## ✅ Шаг 1: Создайте аккаунт Supabase (5 минут)

1. Откройте [supabase.com](https://supabase.com)
2. Нажмите **"Start your project"**
3. Войдите через GitHub (рекомендую) или email
4. Нажмите **"New Project"**
5. Заполните:
   - **Name:** `audiotore`
   - **Database Password:** (придумайте надёжный пароль, сохраните его!)
   - **Region:** выберите ближайший к вам (например, Frankfurt для Европы)
   - **Pricing Plan:** Free
6. Нажмите **"Create new project"**
7. Подождите 1-2 минуты пока проект создастся

## ✅ Шаг 2: Создайте таблицы базы данных

1. В Supabase перейдите в **SQL Editor** (иконка базы данных слева)
2. Нажмите **"New query"**
3. Скопируйте весь код из файла `supabase-schema.sql` (в корне проекта)
4. Вставьте в SQL Editor
5. Нажмите **"Run"** (или Ctrl+Enter)
6. Должно появиться сообщение "Success. No rows returned"

## ✅ Шаг 3: Включите аутентификацию

1. Перейдите в **Authentication** (иконка замка слева)
2. Откройте **Providers**
3. Убедитесь, что **Email** включён
4. Опционально: включите **Google** для входа через Google аккаунт

## ✅ Шаг 4: Настройте приложение

Ключи Supabase уже добавлены в файл `src/lib/supabase.ts`:
- Project URL: `https://ndsrvrdzvqekokikgxhb.supabase.co`
- Anon Key: уже настроен

## ✅ Шаг 5: Загрузите на GitHub

1. Скачайте новую папку `dist`
2. Загрузите на GitHub (замените старые файлы)
3. Подождите 1-2 минуты для обновления

## ✅ Шаг 6: Протестируйте

1. Откройте приложение
2. Нажмите **"ВОЙТИ"** в правом верхнем углу
3. Зарегистрируйтесь с email и паролем
4. Проверьте email для подтверждения
5. Войдите в систему
6. Вы увидите личный кабинет учителя

## 🎯 Что теперь доступно

### Для учителя:
- ✅ Регистрация и вход в систему
- ✅ Личный кабинет с тремя вкладками:
  - **Мои песни** - управление песнями
  - **Результаты** - просмотр результатов учеников
  - **Ссылки** - создание уникальных ссылок для классов
- ✅ Создание уникальных ссылок для учеников (например: `yoursite.com/join/ABC123`)
- ✅ Просмотр всех результатов учеников

### Для ученика:
- ✅ Регистрация по уникальной ссылке учителя
- ✅ Выбор песен из каталога учителя
- ✅ Выполнение упражнений
- ✅ Автоматическое сохранение результатов

## 📊 Структура базы данных

```
Teachers (Учителя)
├── id (UUID)
├── email
├── name
└── created_at

Songs (Песни)
├── id (UUID)
├── teacher_id (связь с учителем)
├── title
├── artist
├── cover_url
├── difficulty (easy/medium/hard)
├── tags (массив)
├── lyrics_data (JSON с пропусками)
└── created_at

Students (Ученики)
├── id (UUID)
├── teacher_id (связь с учителем)
├── first_name
├── last_name
├── class_name
└── created_at

Results (Результаты)
├── id (UUID)
├── student_id (связь с учеником)
├── song_id (связь с песней)
├── gap_answers (JSON)
├── translations (JSON)
├── total_gaps
├── correct_gaps
└── completed_at

ClassLinks (Ссылки на классы)
├── id (UUID)
├── teacher_id (связь с учителем)
├── link_code (уникальный код)
├── class_name
└── created_at
```

## 🔒 Безопасность

- ✅ Row Level Security (RLS) включён
- ✅ Учителя видят только свои данные
- ✅ Ученики могут только добавлять результаты
- ✅ Песни доступны для чтения всем

## 🐛 Решение проблем

### Проблема: Не могу войти
**Решение:** Проверьте, что email подтверждён (приходит письмо от Supabase)

### Проблема: Таблицы не создались
**Решение:** Проверьте SQL Editor на ошибки, выполните скрипт заново

### Проблема: Результаты не сохраняются
**Решение:** Проверьте политики RLS в Supabase
